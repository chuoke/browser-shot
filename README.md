# BrowserShot — Webpage Screenshot

A powerful browser screenshot extension for Chrome and Edge. Capture anything you see, exactly the way you need it — all processed locally, no uploads, no tracking.

## Install

- **Chrome Web Store**: _coming soon_
- **Microsoft Edge Add-ons**: _coming soon_

## Features

### Flexible capture modes

- **Visible viewport** — grab what you see right now
- **Full page** — auto-scrolls and stitches the whole page into one long image (fixed/sticky elements are hidden to avoid duplicates)
- **N screens** — capture exactly 2–5 screens of content
- **Region** — drag to select any area, with optional aspect-ratio constraints
- **Element** — click any element to capture it precisely
- **Right-click menu** — capture an image, selected text, or launch any capture mode
- **Delayed capture** — 3/5/10s countdown, perfect for hover menus and transient states

### Output tailored to your target

- Built-in size presets for **Product Hunt, Instagram, Facebook, X, YouTube, LinkedIn, Pinterest, Xiaohongshu**, WeChat covers and more — one click crops & scales to the exact recommended dimensions
- Custom presets — save your own sizes
- Formats: **WebP** (default), PNG, JPEG with adjustable quality

### Built-in editor

- Annotate: pen, arrow, text, mosaic, rectangle, numbered markers
- Frame & background: solid color, gradients, padding, radius, shadow
- Device frames: wrap your shot in a browser or phone mockup (light/dark)
- One click to copy or download

### Stay organized

- Capture history with search, filters and batch download
- Filename templates with placeholders (host, path, date, sequence…)

### Privacy first

Everything happens locally in your browser: **no accounts, no uploads, no tracking, no network requests**.
